# kanban_board

Канбан-дошка з колонками «Зробити», «У роботі», «Готово». Картки можна додавати, переміщати, позначати кольором і видаляти зі скасуванням. Є світла й темна тема. Дані зберігаються в `localStorage`.

## Правила

- Увесь застосунок — один файл `index.html` (HTML, CSS і JavaScript разом). Без фреймворків, бібліотек і залежностей.
- Інтерфейс і коментарі в коді пишемо українською.
- Зміни робимо маленькими. Одна зміна — одна задача.
- Перед великою зміною спершу покажи план і дочекайся згоди.
- Формат збережених даних не змінюй без вагомої причини, бо інакше в користувачів пропадуть картки. Ключі: `kanban-cards` (масив `{ id, text, status, createdAt, color }`) і `kanban-theme`.
- Текст карток виводимо лише через `textContent`, ніколи через `innerHTML`.
