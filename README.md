# kanban_board

Канбан-дошка для планування завдань. Увесь застосунок — один файл `index.html` (HTML, CSS і JavaScript без фреймворків і залежностей).

Дошка має три колонки: «Зробити», «У роботі», «Готово». Картки можна додавати з пріоритетом (низький, середній, високий), переміщати між колонками, позначати кольором (жовтий, синій, червоний) і видаляти з можливістю скасування. Є світла й темна тема.

## Як запустити локально

Встановлювати нічого не потрібно. Відкрийте `index.html` у браузері: двічі клацніть файл або виконайте в терміналі з папки проєкту:

```bash
open index.html
```

На Windows: `start index.html`, на Linux: `xdg-open index.html`.

Фонове фото завантажується з інтернету (Wikimedia Commons). Без інтернету дошка працює зі звичайним фоном.

## Де зберігаються дані

Дані зберігаються лише у вашому браузері, у `localStorage`:

- `kanban-cards` — картки (текст, колонка, колір, пріоритет, дата створення);
- `kanban-theme` — вибрана тема.

Дані не надсилаються на сервер і не синхронізуються між браузерами чи пристроями. Якщо очистити дані сайту в браузері, картки зникнуть.
